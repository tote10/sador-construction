Full SRS (Software Requirements Specification) for Sador Construction Website
Project Name: Sador Construction Official Website
Client: Sador Construction
Type: General Contractor (Buildings, Roads, Infrastructure & Other Civil Works)
Main Goals:

Attract new clients (leads)
Showcase completed & ongoing projects
Build trust and professional image


1. Functional Requirements
Admin Panel (Very Important)

Secure login (email + password)
Dashboard
Manage Services (Add, Edit, Delete, Reorder)
Manage Projects (Add, Edit, Delete)
Project title
Category (Building, Road, Infrastructure, Other)
Description
Location
Year / Duration
Status (Completed / Ongoing)
Multiple photos (Before & After support)
Client name (optional)

Manage Testimonials
Manage Team members (optional later)
Manage Homepage content (hero section, stats, etc.)
Contact form submissions viewer
Basic SEO settings (title, meta description)

Public Website Features
Home Page

Hero section with strong image/video + "Get Free Quote" button
Company overview
Services highlight (cards)
Featured Projects
Why Choose Sador (trust points)
Testimonials
Stats (Years of experience, Projects done, Happy clients, etc.)
Contact form

Other Pages

About Us
Services (detailed with icons/images)
Projects / Portfolio (with filters: All, Buildings, Roads, Infrastructure, Completed, Ongoing)
Contact Us (with map if possible)

Must-Have Features

Fully responsive (mobile-first)
Fast loading
WhatsApp floating button + click-to-call
Contact/Quote form with notification
Image gallery + lightbox
Basic SEO optimization
Google Analytics ready


2. Non-Functional Requirements

Secure admin panel
Mobile friendly
Loading time < 3 seconds
Easy to maintain by non-technical person
Scalable for future features (blog, tender section, client portal, etc.)
Using Next.js 15 (App Router) as you chose Option 1.
No MongoDB. For this project, Supabase (PostgreSQL) is much better because it gives you:
Free database
